# NordBits.no

Static website for **NordBits.no**.

## Local preview

Open `index.html` directly in a browser, or from PowerShell:

```powershell
cd D:\NordBits
python -m http.server 8080
```

Then open `http://localhost:8080`.

## GitHub Pages

The site is designed to be published directly from the repository root on the `main` branch.

Files:
- `index.html`
- `style.css`
- `script.js`

No build step or framework is required.
